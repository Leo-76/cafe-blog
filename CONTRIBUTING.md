# Contributing

## Setup

```bash
git clone https://github.com/Leo-76/cafe-blog.git
cd cafe-blog
composer install
```

## Running tests

```bash
vendor/bin/phpunit
```

## Code style

```bash
vendor/bin/pint
```

## Pull Request guidelines

1. Fork and create a feature branch: `git checkout -b feature/ma-fonctionnalite`
2. Write tests for any new behaviour
3. Ensure all tests pass and code style is clean
4. Open a Pull Request against `main` with a clear description

## Reporting issues

Please include PHP version, Laravel version, and steps to reproduce.
